# CRM — Customer Relationship Management System

## Project Overview

A full-stack Customer Relationship Management application designed to help businesses manage customers, leads, sales opportunities, follow-ups and sales performance.

## Technology Stack

### Frontend
- React.js
- JavaScript ES6+
- Tailwind CSS
- React Router
- Axios
- Recharts

### Backend
- Python
- Django
- Django REST Framework
- JWT Authentication

### Database
- PostgreSQL

### Development Tools
- Visual Studio Code
- Git and GitHub
- Postman

## Core Modules

1. Authentication and Authorization
2. Dashboard
3. Customer Management
4. Lead Management
5. Sales Pipeline
6. Activities and Follow-ups
7. Reports and Analytics
8. User and Team Management

## User Roles

- Administrator
- Sales Manager
- Sales Employee
